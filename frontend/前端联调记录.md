# 前端联调记录（林豪）

> 安排说明：林豪负责前端联调与接口适配（原分工偏前端，本次补齐该部分工作）。

## 1. 联调环境
- 后端：`uvicorn app.main:app --host 0.0.0.0 --port 8000`（mock 模式）
- 前端：`frontend/index.html`（真实调用 `/api/v1/chat`）
- 打开方式：启动后端后浏览器访问 `http://127.0.0.1:8000`（根路径即前端页）

## 2. 前端对接要点
| 场景 | 前端处理 |
|---|---|
| type=question | 显示追问气泡，等待用户回答，同 session_id 继续发送 |
| type=result | 渲染报告卡片：主推/备选科室、判断依据、挂号指引、院内导航、话术复制、提醒、免责声明 |
| type=urgent | 红色急症告警，展示拨打 120 引导，终止常规对话 |
| 422 | 提示"输入 1~4000 字"，不创建会话 |
| 网络失败 | 提示重试，恢复发送按钮 |
| 发送中 | 禁用发送按钮，防重复提交 |

## 3. 实测记录（2026-11）
| 用例 | 输入 | 结果 |
|---|---|---|
| 多轮追问 | 我肚子疼了两天，偶尔反酸 → 是成年人 | 消化内科报告 ✅ |
| 急症 | 剧烈胸痛，出冷汗 | urgent/emergency 红色告警 ✅ |
| 改口 | 胸口闷 → 说错了…而是肚子疼 | 消化内科报告 ✅ |
| 追问上限 | 不知道 ×3 | 兜底综合门诊 ✅ |
| 校验 | 空消息 / 4001 字 | 422 ✅ |
