# 智能导诊与挂号导航助手

> 团队：**门诊排队** ｜ 项目：智能导诊与挂号导航助手
> 2026 秋软件工程与软件工程实践 · 团队作业

## 项目简介

面向"不知道该挂哪个科、面对挂号平台无从选择"的患者，提供**诊前分诊导航的行动指引**：
患者用自然语言描述症状，系统经过急症拦截、多轮追问与知识检索，输出
「主推科室 + 备选科室 + 判断依据 + 挂号指引 + 院内导航 + 沟通话术 + 就医提醒」的结构化报告。

系统**不做在线问诊、不做诊断、不开处方、不承诺疗效**，全程标注"仅供参考，不替代医生诊断"。

## 核心流程

```
症状输入 → 信息抽取(NLU) → 急症拦截(纯代码规则) → 多轮追问(状态机)
        → RAG 知识检索(规则库+向量) → LLM 结构化生成(白名单校验) → 结构化报告
```

## 技术栈

| 层 | 技术 |
|---|---|
| 前端 | 墨刀原型（设计稿）+ Web 演示页（frontend/index.html） |
| 后端 | Python 3.12 / FastAPI / Pydantic v2 |
| 知识库 | SQLite（5 张表：科室/规则/红旗信号/医院/知识文档） |
| 大模型 | OpenAI 兼容协议（豆包/DeepSeek），默认 mock 模式免 Key 演示 |
