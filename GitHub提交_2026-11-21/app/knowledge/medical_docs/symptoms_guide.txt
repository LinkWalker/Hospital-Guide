# 胸痛、胸闷就诊提示

胸痛、胸闷、心慌、心悸等症状首先需要考虑心血管系统问题，建议优先挂心血管内科进行排查。如果胸痛伴随出冷汗、持续不缓解、放射到左肩或手臂，属于紧急情况，应尽快就医。

# 咳嗽、发热就诊提示

咳嗽、咳痰、发热、咽痛等症状多属于呼吸系统问题，建议挂呼吸内科。高烧持续不退或伴随呼吸困难，属于需要尽快就医的情况。

# 腹痛、胃肠不适就诊提示

腹痛、胃胀、反酸、恶心、呕吐、腹泻等症状建议挂消化内科。剧烈腹痛、频繁呕吐、严重腹泻属于需要尽快就医的情况。

# 头痛、头晕就诊提示

反复头痛、头晕、失眠、偏头痛等症状建议挂神经内科。剧烈头痛、突然的严重眩晕属于需要尽快就医的情况。

# 皮肤问题就诊提示

皮疹、瘙痒、荨麻疹、过敏、湿疹等皮肤问题建议挂皮肤科。如伴随呼吸困难等过敏严重表现，属于紧急情况。

# 关节与骨骼问题就诊提示

关节痛、腰背痛、颈肩痛、膝盖疼痛等骨骼肌肉问题建议挂骨科；若伴有多关节对称性疼痛、晨僵，可考虑风湿免疫科。

# 耳鼻喉问题就诊提示

声音嘶哑、耳朵痛、听力下降、鼻塞、鼻炎等症状建议挂耳鼻喉科。

# 眼科问题就诊提示

眼睛痛、眼红、视力模糊、畏光、眼痒等症状建议挂眼科。

# 泌尿系统问题就诊提示

尿频、尿急、尿痛、排尿困难、血尿等症状建议挂泌尿外科；若伴腰痛、发热等，需尽快就医。

# 内分泌问题就诊提示

乏力、消瘦、多饮多尿、口渴等全身性症状建议挂内分泌科，排查内分泌代谢问题。
