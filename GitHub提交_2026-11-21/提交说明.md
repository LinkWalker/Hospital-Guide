# GitHub 提交说明

## 这是什么

这是 Alpha 冲刺的干净提交包，只包含需要进 GitHub 的代码、文档和贡献证据。

## 不包含

- `.env`（本地密钥）
- `triage.db`（可能含历史记录）
- `.venv`、`__pycache__`、测试临时目录
- Vlog 视频、博客图片、答辩 PPT（这些走博客/网盘/课程平台，不进仓库）

## 推送到 GitHub

如果仓库还没有代码：

```bash
git init
git add .
git commit -m "Alpha: 分诊报告 -> 医院 -> 挂号 -> 导航"
git branch -M main
git remote add origin https://github.com/<owner>/<repo>.git
git push -u origin main
```

如果仓库已有代码，建议新建分支：

```bash
git checkout -b alpha-submit
git add .
git commit -m "Alpha: 提交冲刺代码与材料"
git push origin alpha-submit
```

然后在 GitHub 发 PR，合并到 main。

## 提交前检查

- [ ] `.env` 没有进仓库
- [ ] `triage.db` 没有进仓库
- [ ] `.venv`、`__pycache__` 没有进仓库
- [ ] `README.md` 能按步骤跑起来
- [ ] `pytest` 结果与 README 一致
- [ ] `contributions/` 里 12 个贡献包齐全
- [ ] 没有真实患者信息、手机号、身份证号
